# Prodigy-Nexus
How to Use Prodigy Nexus

1. Download or clone the repository.
2. Open your browser’s extensions page:

* Chrome: chrome://extensions
* Edge: edge://extensions

3. Enable Developer Mode in the top-right corner.
4. Click Load Unpacked.
5. Select the Prodigy Nexus folder.
6. The extension should now appear in your browser toolbar.
7. Open the extension and enjoy the full Prodigy Nexus interface and tools.

Notes

* Make sure all files stay inside the same folder after downloading.
* If the extension does not load, refresh the extensions page and try again.
* Some features may require refreshing the target webpage after enabling the extension.
